# Grocery Store Management System

A database-driven application designed to streamline the operations of a grocery store, including inventory management, customer service, and employee management. This system helps improve store efficiency, monitor stock levels, and provide personalized services to customers.

## 📌 Features

- 🛒 **Inventory Management**
  - Add, update, and delete products
  - Track product availability and stock levels
  - Generate restocking alerts

- 👥 **Customer Management**
  - Register new customers
  - Track customer orders and purchase history
  - Manage loyalty points and discounts

- 🧑‍💼 **Employee Management**
  - Add and manage employee records
  - Assign roles and shifts
  - Track performance metrics

- 💵 **Sales & Billing**
  - Generate bills and invoices
  - Process payments (cash, card, digital wallets)
  - Maintain daily sales reports

- 📊 **Reports & Analytics**
  - Sales trends and inventory usage reports
  - Employee performance reports
  - Customer purchase analysis

## ⚙️ Technologies Used

- Database: ORACLE
- Backend: Python / Flask
- Frontend: HTML, CSS
- Tools: VSCode, GitHub

## 💾 Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/SteffiDorothy/Projects.git

2. **Navigate to the Grocery Store Management System folder**
   ```bash
   cd grocery-store-management-system

3. **Set up the database**
   - Run the provided SQL scripts to create tables.
   - Update database connection settings in the code.

4. **Run the application**
   ```bash
